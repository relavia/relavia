## 1. 检索口径声明（必读）

1. 本次为**初步敲除检索**，方法仅限公开网络检索（搜索引擎可见的网页、GitHub 公开页面、应用商店与公司登记的公开镜像页）。
2. 本次**不是**商标局在册检索：未查询任何国家/地区商标局的官方注册数据库，未做相同/近似商标的法律判定。文中涉及商标的条目（如 Crossvia 法国记录）来自第三方商标聚合站的转引，只能作敲除信号，不能作法律结论。
3. 结论用语约定：「查无」指在本次检索范围内未发现，不等于现实中不存在；「印象」指基于检索结果的初步判断，未经注册商/平台实时系统验证。
4. 域名可得性：文中只写公开检索印象（是否查到已注册记录、是否有活跃站点）。**任何域名是否可注册，必须在拍板后以注册商实时查询为准，本文件不断言可注册。**
5. GitHub 组织名是否可注册同理：除已查实被占用的（Panvia）外，其余候选的组织名可得性未逐一实时验证，列入 Step 4 建仓前核查项。

验收对照（方案书 Step 1 验收标准）：「名称无重大撞名与侵权风险（初步检索口径），用户拍板」——本文件的推荐候选均已通过初步敲除口径的筛查，重大撞名项已单列淘汰；正式商标在册检索为方案书 Step 3 的工作，不在本步范围内。

## 4. 推荐候选（逐项检索结论）

### 4.1 第 1 名：Relavia（中文名建议：汇途）

**含义**：relay + via，「经由汇聚中继之路」。正好对应本产品两件事：多协议、多来源在本地汇聚；流量经用户自选节点中转。不含任何代理/VPN 敏感词，中英文发音都顺（四音节但节奏轻快），中文名「汇途」与构成同义。

**检索结论**

- (a) GitHub：以 "Relavia github"、"github.com/relavia organization" 两组词检索，结果中**未出现**名为 Relavia 的仓库或组织（本次检索范围内查无）。命中的均为无关近似词条目（RelVal、RELIA 等学术项目）。
- (b) 同名软件产品/App/公司：**未发现任何名为 Relavia 的软件产品或 App**。公司登记公开镜像中查到数家同名小公司，全部与软件/网络无关：
  - Relavia OÜ（爱沙尼亚，航空运输设备租赁，2015 年登记，公司登记镜像显示状态为清算中）：https://ariregister.rik.ee/eng/company/12936787
  - RELAVIA LIMITED（塞浦路斯，2012 年登记，一家登记镜像显示已解散）：https://companiesregistry.cy/company-details/relavia-limited-306394/
  - Relavia Limited（爱尔兰，控股公司，2025-09-01 设立）：https://www.vision-net.ie/Company-Info/Relavia-Limited-796394
  - Relavia Consulting LLC（美国佛罗里达，2023 年设立）：https://www.bizprofile.net/fl/sarasota/relavia-consulting-llc
  - Relavia Sp. z o.o.（波兰，旅客住宿业，2007 年设立）：https://www.emis.com/php/company-profile/PL/Relavia_Sp_z_oo_en_3630391.html
- (c) 一般网络精确名：精确名结果基本就是上述登记条目；另有一个印尼社区社会测绘项目使用「RELA VIA」字样（Instagram 小账号，影响可忽略）。

**风险点**

- 同名公司在多国登记中存在（造词名的常态），无一在软件领域，但 Step 3 正式商标检索必须覆盖第 9 类（软件）与第 42 类（软件服务）逐法域核查，不能因本次查无而省略。
- GitHub 组织名 `relavia` 是否可注册未实时验证（检索未见占用），建仓前须先占名验证。
- 近似名生态热闹：ReVia（法律科技软件）、Raeliva（远程医疗）等发音相近名存在，属可接受范围，但 Logo 与视觉识别应主动拉开距离。

**域名可得性初步印象**：以 "relavia.com" 为词检索，结果未出现该域名上的公开活跃站点（命中的均为 Raeliva/Revalia 等近似名站点）。印象：relavia.com 未见活跃使用迹象，**是否可注册须以注册商实时查询为准，本文件不断言**。

### 4.2 第 2 名：Pontra（中文名建议：桥途）

**含义**：取拉丁语 pons（桥，词根 pont-）+ -tra（跨越感后缀），「桥」是全套意象里最具体、最易做 Logo 的一个。两音节，中英文都极好发音，中文名「桥途」直白对应。

**检索结论**

- (a) GitHub：查到同名仓库 github.com/jarodl/Pontra，据 Open Hub 项目页说明是一个 iPhone 版小游戏（'gnop' 复刻），体量极小、非网络领域：https://openhub.net/p/Pontra 。仓库名在他人账号下不构成阻碍；组织名 `pontra` 可得性未实时验证。
- (b) 同名软件产品/App：查到 Android 小游戏《Super Pontra》（Zalmay Apps 发行，Google Play 在架），游戏领域、体量小：https://zalmay.com/games/super-pontra-runner-corps/
- (c) 一般网络精确名：精确名结果稀少，主要即上述游戏；搜索结果被近似名大量占据，见风险点。

**风险点**

- **近似名 Pontera 是最大风险**：Pontera 为美国金融科技公司（2012 年以 FeeX 之名创立，2022 年更名 Pontera，累计融资逾 1.6 亿美元），与 Pontra 仅一字之差、读音高度接近：https://grokipedia.com/page/Pontera 。虽领域不同（金融 vs 网络工具），但对方规模与商标布局远大于本项目，Step 3 正式检索若发现其第 9/42 类布局密集，应果断弃用本名。
- 同生态近似名还有 Bonterra（社会公益软件公司），进一步稀释独特性。

**域名可得性初步印象**：域名数据库记录显示 pontra.com 已于 2009-07-23 注册（注册商 Wild West Domains），且 DNS 记录显示其停放在域名停放类服务商处（parklogic/domaincontrol）。印象：**pontra.com 已被注册且大概率为停放状态，原价取得的可能性低**；如选此名，官网域名可能需要退而求其次（如 .org 或加前缀），须在拍板前实时核价。记录来源：https://www.bigdomaindata.com/fuzzy-domains/contra.cloud

### 4.3 第 3 名：Panvia（中文名建议：万途）

**含义**：pan（全、泛）+ via（路），「万途」——与「全主流协议兼容」的产品主张贴合度在所有候选里最高。三音节，中英文发音都自然。

**检索结论**

- (a) GitHub：**用户名 panvia 已被占用**：github.com/panvia 为既有个人账号（名下为 GUI 库的 fork 仓库）：https://github.com/panvia 。这意味着组织名无法使用原名，须用变体（如 panvia-app、panvia-project），是实打实的减分项。另查到开发者 douglasopan 名下有 panvia-releases、panvia-apresentacao 等仓库（见 (b)）。
- (b) 同名软件产品：**Panvia 是一个正在开发中的游戏分发平台/启动器**：据其分发游戏页面说明，游戏经 Panvia 平台分发、带 Windows/Android 安装器；其发布仓库自述为「Panvia 安装包的公开发布」：https://ferroshift.online/ 与 https://github.com/douglasopan 。同为「客户端软件 + 分发」形态，与本项目存在真实混淆面。此外还有：克罗地亚在线农贸平台项目 Panvia（开发商案例页）：https://marketing-mktfatbit.kit.4qcteam.com/portfolio.html ；以及 Panvia Quantum Computer 的站点：https://panviaquantum.com/top-10
- (c) 一般网络精确名：结果即上述平台与项目，外加近似名 Panviva（见风险点）。

**风险点**

- 同名软件分发平台在先且活跃开发中，若对方先做大或先注册商标，本项目后发同名会很被动。
- **近似名 Panviva**：Upland Software（纳斯达克上市公司）旗下的企业知识管理软件产品，仅一字之差：https://builtin.com/job/software-engineer-ii/10131110
- GitHub 组织名被占，与本项目「开源项目以 GitHub 为主阵地」的打法直接冲突。

**域名可得性初步印象**：以 panvia.com 为目标的检索未返回该域名上的明确站点（查不到明确结果）；已确认被占用的相关域名包括 panviaquantum.com。印象：主域名状态不明，须实时查询，**不断言可注册**。

### 4.4 第 4 名（备选）：Waymesh（中文名建议：途网）

**含义**：way（路）+ mesh（网状），「多条路径织成一张网」，对应多协议多节点的汇聚形态。英文母语者一读即懂，中文用户发音稍拗口，是排位靠后的原因之一。

**检索结论**

- (a) GitHub 及开源项目：查到多个小体量同名项目，且集中在网络通信领域：Devpost 上有名为 WayMesh 的黑客松项目（离线 mesh 应急通信）：https://devpost.com/software/built-with/github?commit=Search&page=387&search%5Bplatform_ids%5D%5B0%5D&utf8=%E2%9C%93 ；GitHub 用户 snokvist 的多个仓库以 waymesh 命名做 Meshtastic 相关的 mesh 网络研究（waymesh-node 等）：https://github.heygears.com/snokvist
- (b) 同名软件产品：WAYMESH 为 Fidevo AI Labs 的企业通勤/班车/停车协调产品页（其页面自述为「已完整定义、尚未建成」）：https://waymesh.fidevo.app/
- (c) 一般网络精确名：结果即上述项目与产品，无大体量占用。

**风险点**

- 同名使用者虽小，但与本项目同属「网络连接」大领域，混淆概率高于跨界同名。
- way + mesh 均为通用词，独创性在候选里最弱，商标注册的显著性先天吃亏。
- 仅作备选：当前三名全部在 Step 3 正式检索中出问题时才启用。

**域名可得性初步印象**：域名数据库记录显示 waymesh.com 已于 2025-08-25 经 Namecheap 注册（隐私保护开启）：https://www.bigdomaindata.com/whois/paymesh.online 。印象：.com 已被注册，不可按原价取得。
