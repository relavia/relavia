## 2. 阶段 0 关键裁定与事实汇总

- 正式名 Relavia；爱称「眼睛」（Logo 意象与中文称呼，非商标主体）；口号定版；中文名「汇途」经 Step 3 检索不建议采用（北京汇途科技以同名品牌经营含软件业务），正式中文名悬置，中文侧以爱称「眼睛」行走。
- 新发现近似风险：**Relvia Labs LLC**（美国 AI SaaS，与 Relavia 一字之差）为最高优先近似项，Step 1 精确名检索漏检、Step 3 补检发现；风险等级中，处置：代理检索头号近似项、全项目禁用「Relvia」短称、Logo 与配色主动拉开。不推翻已定名。
- 域名事实：relavia.com 已被注册（2025-03-29，停放未启用）；relavia.org / relavia.io 经 RDAP 查询无注册记录（未注册的强印象，不断言可注册）。
- GitHub：github.com/relavia 实测 404，未发现占用（不排除保留名/冷却期，以实际注册为准）。
- 许可证主线定版 GPL-3.0-or-later；OpenVPN 独立进程、Wintun 官方 DLL 两条集成红线生效。
