## G1/G2 互通与明文（TestRigInteropTCP）

同一节点参数、同一回显目标，7 方法 × 2 服务端：

- sing-box 入站（B）：7/7 方法结果层（自研探测与对照探测均成功）+ 明文层（100 B 与 64 KiB 载荷经两家客户端回显逐字节一致）全过。
- shadowsocks-rust（A）：6/7 全过；**xchacha20-ietf-poly1305 例外——shadowsocks-rust v1.25.0 不实现该 2017 方法**（其自身报 `unsupported method`），属参考实现缺位，非被测缺陷；该方法的互通证据由 B 腿承担。rig 中该腿显式 Skip 并注明原因。
- 探测时延（本机环回）：自研 0.63–1.19 ms，对照 1.13–8.66 ms，自研不劣化（G6 时延项在本子集达标）。

**UDP 腿（TestRigInteropUDP）本机未跑成**：本机沙箱对环回 UDP 数据报本身 EPERM（裸 UDP 探针实测不通，与被测实现无关），rig 以真实探针判定后显式 Skip 并记录原因；CI（GitHub ubuntu）UDP 环回可用，该腿在 CI 判决。**在 CI 判决回来之前，G1/G2 的 UDP 部分记为未决，不记通过。**

## G3 向量（引擎向量测试 + TestRigStructural*）

- 向量集冻结版：52 条（P0 41、P1 11），引擎逐条双向验证全过（KDF / AEAD 原语 / 2017 与 2022 的 TCP 流与 UDP 包 / 负向量）。
- 结构层实测：固定盐钩子下经中继抓取自研客户端发往真实 rust 服务端的线上字节，与冻结向量逐字节一致（W17-01 请求流、W22-05a 请求流）。
- **跑批中发现并更正一处向量/引擎同源误读**：2017 TCP 响应流不带地址头（原期望误按请求方向模型生成）。处置与依据见主规格 §6 第 8 条与向量清单 §G：原期望加 `withdrawn` 标记保留，更正条目 W17-21…24、W17-26 入库。此更正同时关闭了线上流向量「第二来源」的悬置项——rust 与 sing-box 两家活互通即第二来源实测。

## G4 错误分类（TestRigErrorLayer，一期子集）

用例：错密码 ×（aes-256-gcm、2022-blake3-aes-256-gcm）、服务端不可达 ×2。结局（失败）与分类（handshake_failed）两客户端全一致。裁决两条：

1. **探测层分类口径**：自研引擎在拨号层把连接拒绝分类为 `network`（数据面口径，精确），对照探测把一切探测失败归为 `handshake_failed`。按内核接口契约（TestHandshake 的失败是结果、Error 为 KindHandshakeFailed），复合适配器的探测层统一映射为 `handshake_failed` 并保留引擎原始错误为 cause；引擎本身分类不变。此为口径对齐，非缺陷。
2. **对照组怪癖**：错密码 + 2017 时 rust 服务端静默丢弃流量，对照探测以其内部超时（20 s）的 Go error 形式收场而非失败结果；自研探测同场景返回失败结果。结局与分类一致，rig 中归一化后比对并在此留档。时机一致性：两方同为约 20 s 超时收场，一致。

未覆盖（一期范围外或待补）：2022 时间戳过期/超前的**服务端行为级**比对（NEG-04，引擎侧校验已由向量 W22-06 与单元测试覆盖，行为级待 UDP/TCP 行为集补齐时一并跑）；UDP 重放（NEG-07，随 UDP 腿在 CI/后续补跑）。

6 个目标（2017 包解码、2022 AES 包解码、2022 ChaCha 包解码、2017 流解码、2022 流解码、地址解析），种子语料来自冻结向量。本地短跑 20 s/目标全过、零崩溃；CI 已设 30 s/目标短跑步。**发布配额（每目标累计 ≥8 h）未执行**——需在发布候选阶段以长跑补齐，本工作包不宣称 G5 通过。

## G6 性能哨兵（未达线 + 分析）

环回 4 MiB 回显吞吐：自研 217–231 MiB/s，对照 381–456 MiB/s，**比值 0.51–0.57 < 0.70 门线**。按规格 §4.6，G6 未达 = 交分析、不自动判失败，分析如下：

- 形态差异：对照（sing-box）走其内部缓冲/池化路径；自研流写入按块 Seal 两次（长度块 + 载荷块，块长 0x3FFF），每块两次新分配、无缓冲复用，分配频次约为对照的数倍，环回纯 CPU 场景下即表现为吞吐差。
- 时延项达标：小载荷探测时延自研全面更低（见 G1/G2），无连接建立劣化。
- 处置：不在一期为哨兵数字做定向优化（握手面不是数据面）；二期数据面实现时以缓冲池 + 批量写为既定要求，并在二期跑批复测 G6。在此之前，`auto` 档默认仍为 singbox（出厂默认档），自研数据面未承载真实流量，哨兵未达不构成发布风险。

## G7 回退演练（TestRigFallbackDrill）

`auto` 档 + 不可达节点：首次探测走自研并失败 → 节点按指纹钉住 sing-box（日志留痕）→ 第二次决策点直接走 sing-box（日志留痕），无连接中途切换；带 plugin 字段的节点从一开始即固定 sing-box 并记录原因（plugin 传输不在自研范围）。三档（singbox/auto/selfdev）路由与钉住/变更失效/手动重置语义由复合适配器单元测试覆盖，全过。
