## 文案口径

图中文字优先取自三语词条的简中版（app/locales/zh-Hans，
如「TUN 全局」「准入：TCP 可达」「撤销风险确认并停用」）；
节点名与域名（*.example.net 等）、延迟与流量数字为示意
数据，不对应任何真实节点。已连接图的流量数字是版式示意：
注意安卓 TUN 路径当前不提供流量计数（见
docs/android产品界面接入.md §3 的 QueryTraffic 诚实口径）。
**裁定（2026-11-14）**：经查 libbox 绑定面，安卓 TUN 路径
无进程内可用的流量计数接口（证据见该文 §9 增补）——安卓端
整卡不渲染；桌面端经 sing-box 适配器有真实计数来源，保留
该卡。**不得显示假数字**，此裁定为定版。

### 与拆解规格的偏差记录（评审时请一并裁定）

1. 导入方式行高 88dp（拆解 §3.9 写 76dp / 说明一行）：
   §4.4 定稿说明句在 13sp 下需两行，行高按 §3.2 的自适
   应口径放宽到 88dp，结构（一行一事、点开才展开）不变。
2. 新用户英雄卡高约 206dp（拆解 §1.2 指南 168–196dp）：
   状态句 + 两行说明 + 56dp 按钮 + 提醒行同卡时的内容
   自适应结果，未删减任何定稿文案。
3. 节点行星标 / 溢出与名称行对齐（非整行垂直居中）：
   使副行获得全宽，地址 · 协议 · 延迟三段不被截断（拆解
   §3.1 的三段格式在 360dp 宽下与居中星标共存时必截断
   延迟，量测后改此对齐）。
4. 已选中行信号取「主色浅染 + 左 3dp 竖条」两样（拆解
   §2.4 要求至少两样），未加「已选中」胶囊：v2 中胶囊
   与行底同色融合读成纯文字，且名称行已有志愿者徽标。
5. 英雄卡风险提醒行作 11sp 单行（实现若按 12sp 折行，
   卡高自适应即可）；弹层与各页文案未改动任何定稿句，
   风险要点未弱化（完整文本仍以方案书 §7.3 为准）。
6. 深蓝档仅出首屏对比图；其余各页实现时按同一令牌表
