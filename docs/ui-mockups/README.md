## 设计令牌（实现时照此取值）

- 画布：竖屏，内容边距 16dp，卡片间距 10dp，卡片圆角 10dp，
  按钮圆角 8dp，按钮高度 ≥ 40dp（触控目标整改方向对齐
  KI-14 的 48dp 指南，评审时一并定）
- 色板：背景 #F6F7F9；卡片 #FFFFFF；边框 #E4E7EC；
  主色 #2E54EB（按钮/选中/链接）；主色深 #2340B4（徽标字）；
  主色浅底 #E8EEFE；正文 #1A1D21；次级 #697181；
  弱提示 #949CA8；成功 #12966C / 浅底 #DEF5EC；
  警告 #C97C12；危险 #D03C3C / 浅底 #FCE9E9
- 字阶：页标题 17sp 粗体；卡片标题 14sp 粗体；正文 13–14sp；
  节点名 15sp 粗体；副行/说明 11–12sp 次级色
- 品牌标记：单眼抽象标记（双睑弧线＋实心瞳点＝节点汇聚，
  沿 Step 3 方向 1「途入瞳心」），不得改为写实眼球
- 结构与现有 ui 保持一致（四标签：节点/导入/日志/设置；
  节点页操作行；页脚运行模式行），本轮视觉实现不改信息
  架构，只换呈现

## 文案口径

图中文字优先取自三语词条的简中版（app/locales/zh-Hans，
如「TUN 全局」「准入：TCP 可达」「撤销风险确认并停用」）；
节点名与域名（*.example.net 等）、延迟与流量数字为示意
数据，不对应任何真实节点。已连接图的流量数字是版式示意：
注意安卓 TUN 路径当前不提供流量计数（见
docs/android产品界面接入.md §3 的 QueryTraffic 诚实口径）——
视觉实现评审时需一并裁定：接 libbox 计数面，或该卡在安卓
改为不显示，**不得显示假数字**。
