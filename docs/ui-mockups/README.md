## v4（瞳心）：先审计，后设计

触发：用户裁定（2026-11-19）——说实话现界面不好看、操作也未必方便，界面美观与易用是第一优先级。本批仍只出效果图与设计说明，用户点头后才实现；实现仍不得偏离本章口径。与 v3 的关系：v3 的信息架构与文案口径（首屏三件事、一键链、风险 sheet、为你选好≤3 行、四种背景）全部保留，v4 换的是视觉系统与细节交互，不是推倒重来。

### 审计方法

把当前客户端（main `2d762b8`，即 v3 实现）用桌面构建在 Xvfb 里以 360×800 真实窗口渲染，喂真实形态数据（101 个节点、10 个分组的留存存储；新用户空存储；深蓝主题），逐屏抓帧并与代码逐项对照（`app/ui/views.go`、`app/ui/theme.go`、三语语言包）。下面每条发现都有帧或代码出处，不是凭印象说丑。

### 现状审计：丑在哪、别扭在哪

- **A1 全平、没有深度。** 所有表面都是平白卡片 + 1px 描边，压在平灰背景上；hero 卡和任何一张普通卡片长得一模一样，没有阴影与层级系统（调色板里根本没有阴影 token）。第一眼看不出哪块最重要，只能靠读字。
- **A2 连接状态读不出来。** 空闲 / 连接中 / 已连接 / 失败四态共用同一张白卡，只靠一圈细边颜色 + 一行小字区分；已连接时主按钮「断开」是描边次按钮，长得像次要操作；顶栏状态点是一个无文字的灰圈，不看字不知道连没连。
- **A3 风险短句被拦腰截断。** hero 风险行在真实帧里渲染成「公共节点由志愿者提供，会留…」——一整句合规相关的话被单行布局切掉一半，看起来像坏了，也显得不可信。（v3 效果图里这行本来是完整的，是实现走样。）
- **A4 「为你选好」与列表重复、选中底色出血。** 同一个节点（如 219.100.2.21）同时出现在「为你选好」和下方列表第一行，一屏两遍；选中行的底色 + 左条是整屏通栏出血，和卡片 16dp 内缩的边距体系打架，像渲染事故。
- **A5 节点行没法扫。** 每个池子行都挂同一枚「VPN Gate · 志愿者」胶囊，把每个名字都截成同一个 IP 前缀；一行行长得一模一样。用户最想扫的延迟数字埋在副行中间，和地址、协议同灰同字号；「36 ms / 无响应 / 还没检查 / 检查失败」四种状态共用一个位置一种样式，扫不出谁能用。复杂旗帜（如香港）退化成红块加星花，像通用徽章不像旗。
- **A6 新用户首屏下半屏是空的。** 零节点时搜索框和分组片照样渲染（对着空列表搜什么？）；空状态只是两行灰字飘在页面上，没有容器、没有图形，下半屏约 55% 留白。
- **A7 设置页留白与选中语言不统一。** 语言单选行约 90dp 高、大量死白，而协议偏好行是密集卡片；语言选中只有单选点、协议选中是单选点 + 底色——同一页两种「选中长相」。背景色块里深蓝与墨色是两块分不清的近黑矩形；选中对勾被色块右上角裁掉一半；「跟随系统」色块右半溢出圆角（硬竖切、无裁剪）。
- **A8 导入页状态不诚实。** 池子已经启用并确认过风险时，推荐卡按钮仍写「✓ 启用 VPN Gate」——对勾和「启用」自相矛盾；方式行直接飘在背景上（上面的卡有表面、它们没有）；图标容器一会圆一会方；页标题「导入节点」和标签「导入」重复占高。
- **A9 日志空状态是死胡同。** 空日志页只有一行灰字「暂无日志」，外加一个空时毫无意义的「清空日志」；标题还带括号规格注「连接日志（仅保存在本地）」。
- **A10 图标与触控欠账。** 标签图标是粗细不一的细线条形；「全部检查」是一个没文字的仪表盘小图标，猜不出能点；分组片是大胶囊还截断（「Croatia (LOCA…」）；多个热区仍小于 48dp（Step 18 实测 37dp / 34dp 的挂账）。
- **A11 标题重复。** 导入 / 设置 / 日志的页内大标题与底部（顶部）标签同名，白占一屏高。
- **A12 没有品牌感。** 眼睛标记只在顶栏小小出现一次；颜色、表面、母题没有任何一处说这是 Relavia——和任何 Gio 示例程序可以互换。

### 设计方向：「瞳心」

一句话：把品牌眼睛从顶栏的小标记，提升为首屏的状态仪表——眼睛的「瞳」就是连接状态本身。其余表面退后：页面用浅渐变打底、卡片有真实阴影与 20dp 圆角、按钮有 2dp 深色底边（实现口径），让全屏只有一个视觉主角（hero 状态面板）和一个主行动（一键连接）。

四态视觉语言（图注定义，连接中与失败未单独出图，实现按此执行）：

| 状态 | 瞳环 | 瞳心 | 面板标题区 | 主行动 | 顶栏状态胶囊 |
|---|---|---|---|---|---|
| 空闲 | 白色 38% 空心环 | 空心小环 | 现在没有连接（新用户：先连上一个免费节点 + 说明句） | 白底填充「一键连接…」60dp | 灰点 + 未连接 |
| 连接中 | 白色 30% 轨道 + 白色弧段（实现为旋转扫过） | 实心小点 | 当前阶段原话（正在刷新公共节点… / 正在快速检查节点延迟… / 正在逐个试连最快的节点…，均为既有文案） | 变「取消」描边按钮（面板内） | 蓝点 + 连接中 |
| 已连接 | 整圈成功绿 #3ED598 | 实心绿点 + 光晕环 | 已连接 + 节点名 + 「已自动选中 · 协议 · 延迟」 | 白底填充、危险红字「断开」60dp——大小位置与连接键一致，危险只靠字色 | 绿点 + 已连接 |
| 失败 | 危险色 #FF9D8A 整圈 | ✕ | 连接失败 + 大白话原因（≤2 行） | 白底填充「换一个节点重试」；次行动「查看原因」跳日志页并定位到该条失败记录 | 回到未连接 |

原则：状态靠颜色 + 形状 + 文字三重编码，不只靠颜色（色觉无障碍）；四态共用同一块面板、同一个瞳心位置，状态切换时布局零跳动。

### 哪些保持不变

- **信息架构与主路径**：首屏三件事、一键连接链（同意 → 刷新 → 快速检查 → 试连）、风险确认走底部 sheet、普通用户主路径不出现协议选择 / 导入表单 / 路由配置（裁定 2026-11-14 不变）。
- **风险文本逐字**：`risk.*` 全套（sheet 标题、三条要点、完整说明正文、hero 风险短句）与语言包原文一致，本批只改容器与排版，不改一个字。
- **能力诚实口径**：不可用能力仍如实置灰并在组内写原因；不画客户端没有的功能——本批所有元素都能对应到现有能力（状态胶囊 = 现有连接状态；「刚刚测到最快」= 既有徽章口径；日志定位 = 失败原因已有的日志落点）。
- **数据口径**：不写「最快节点」式宣称（只有「一键连接最快节点」这一既有按钮口径与「刚刚测到最快」的实测标签）；无任何遥测 / 云端类暗示；效果图中的节点名、延迟、计数均为示意数据，按本目录惯例。
- **i18n 纪律**：实现时新增文案（状态胶囊、上次连接 / 收藏标签、找到 N 个、日志说明句、导入状态条等，约十余键）必须三语齐全再合并；本批效果图只出简体中文版，与 v1–v3 惯例一致。
- **四种背景与既有设置项**：背景四档、协议偏好、运行模式、能力 / 信任 / 更新各组的内容与行为不变，只换行型与容器。

### 与 v3 的偏差（如实记录）

1. **导航位置**：v3 是顶部统一分段标签，v4 改底部标签栏——拇指可达性优先，且顶栏让位给品牌 + 状态胶囊。这是结构变更，实现工作量主要在此与 hero 面板，其余为换皮与行型调整。
2. **hero 形态**：v3 的 hero 是白卡 + 小状态行，v4 是深渐变状态面板 + 瞳心勋章——回应审计 A1 / A2 / A12，是本批最大的视觉主张，请用户重点看这两张首屏图。
3. **选中行底色**：v3 实现为整屏出血（审计 A4 认定为缺陷），v4 改内缩圆角——与 v3 效果图本身的卡内选中画法一致，属于向效果图回归。
4. **新用户空状态**：v4 的零节点规则（不渲染搜索 / 分组片 + 水印空状态）本批未单独出图，版式借 04-日志的水印区式样；若用户认可方向，实现前可补一张新用户首屏图再确认。
